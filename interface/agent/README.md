# Agent interface

The local page's **Ask assistant** view runs the existing root `agent/runtime.cjs` in the resident process. Its tools call the actual listening HTTP origin (including a dynamically assigned port). Passwords and challenges remain in the normal login form. Model configuration uses the root runtime's `OPENAI_API_KEY` and optional `EUFY_AGENT_MODEL`; normal browsing and local snapshots work without model configuration.

`http.cjs` is a thin interface adapter, not another business API. `POST /interface/agent/turn` accepts only `{id,text,locale}` from the local page and returns 202 as soon as the resident owns the turn. The caller-generated ID is durable: repeating an accepted ID does not call the model again. A different concurrent turn returns `TURN_BUSY`. Disconnecting the submitting browser does not abort the turn. `GET /interface/agent/state` returns conversation messages, service range receipts and authoritative job views through the existing HTTP client. Polling this endpoint never invokes the model.

The default state file is `output/agent/interface-<actual-port>.json`, overridable with `EUFY_INTERFACE_AGENT_STATE` or `createServer({agent:{statePath}})`. One origin and resident process owns it; it must not be shared between origins/processes. Browser refresh reattaches to the same conversation and jobs. Restarting the resident on the same origin restores saved conversation/tool state. A turn interrupted by a process restart is explicitly marked interrupted; it is never automatically replayed. Follow-up messages use the runtime's existing persisted request/receipt identity. Existing jobs remain readable after logout; new cloud operations require normal login.

The interface preference controls labels. **Response language** separately selects the runtime's `preferredLocale` turn option, defaulting to the interface locale. Neither option rewrites user text, device names or tool/time arguments. Previous messages retain their original language. Browser storage saves mode, response preference and an unsent draft; resident state is authoritative for accepted work. The interface is single-account and local, matching the existing service.

`fixture.cjs` and `browser-fixture.cjs` are test-only. They inject synthetic inventory/capture and the installed SDK's `ScriptedModel`; they are never loaded by production. See [validation](VALIDATION.md) for reproduction and limitations.

The [workspace contract](../workspace/README.md) adds `workspace_present` to the same root runtime. The snapshot includes its normalized reference presentation. Optional repeated `jobId` query parameters request current durable jobs for restored pins; each response retains `jobId` even when lookup fails. `POST /interface/agent/export` accepts only `{receiptId}` from the local origin and reuses the existing export identity. This interface adapter adds no v1 business API or alternate execution path.
